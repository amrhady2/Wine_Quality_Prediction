# Wine-quality exploration

Python scripts and notebooks exploring a wine-quality dataset, including missing-value handling, plots, and prediction experiments.

## Start here

- `Wine_quality_prediction/main.py` — exploratory analysis and preprocessing.
- `Wine_quality_prediction/Quality Prediction.py` — initial visual exploration.
- `Wine_quality_prediction/Quality Prediction_ver_2.ipynb` — notebook experiments.
- `Wine_quality_prediction/winequalityN.csv` — input data.

Run scripts from `Wine_quality_prediction/` because their input paths are relative to that directory. The scripts use pandas, NumPy, seaborn, and Matplotlib; notebooks may require additional ML packages.

**Status:** historical learning project. Model results have not been independently reproduced. Dataset provenance and reuse terms should be verified before redistribution.
